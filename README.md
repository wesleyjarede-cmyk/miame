# Miami Store — site

Site de apresentação da loja de roupas Miami Store (@miamistore.ura).
HTML, CSS e JS puros: abra o `index.html` no Chrome, sem instalar nada.

- `js/dados.js`: contato, categorias e produtos. **Edite só aqui.**
- `css/marca.css`: cores e fontes da marca.
- `css/estilo.css`: layout das seções.
- `js/main.js`: abertura com vídeo, coleções e vitrine 3D.
- `videos/`: vídeo de abertura em 1080 e 720 (fora do Git).
- `originais/`: vídeo original enviado (fora do Git).

Situação e pendências: veja `PROGRESSO.md`.
